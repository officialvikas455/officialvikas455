## 🚀 Featured Engineering Projects

### 1. 🎥 Real-Time Video Conferencing Platform
> **Enterprise-grade peer-to-peer audio/video calling application with instant messaging, dynamic room generation, and secure meeting controls.**

- **Tech Stack:** `React` • `Node.js` • `Express.js` • `MongoDB` • `WebRTC` • `Socket.io` • `Tailwind CSS` • `JWT`
- **Key Highlights:**
  - 🔄 **P2P Streaming:** Sub-100ms ultra-low latency mesh networking via native WebRTC media channels.
  - ⚡ **Signaling Layer:** Event-driven room discovery and ICE candidate exchange orchestrated over Socket.io.
  - 🔒 **Security:** Tokenized meeting rooms, protected middleware routes, and Bcrypt password encryption.
  - 👥 **Collaboration:** In-meeting live chat, participant roster toggles, and responsive audio/video controls.
