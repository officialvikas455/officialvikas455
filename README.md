* **🔄 Peer-to-Peer Media Channels:** Sub-100ms ultra-low latency mesh communication directly between clients using WebRTC.
* **⚡ Event-Driven Signaling:** Real-time room discovery, SDP offer/answer handshakes, and ICE candidate negotiation via Socket.io.
* **🛡️ Security & Access:** Secure JWT-based room authorization, meeting passcodes, and protected backend middleware.
* **💬 In-Room Interaction:** Real-time participant roster updates, screen-sharing, and synchronous chat messaging.
